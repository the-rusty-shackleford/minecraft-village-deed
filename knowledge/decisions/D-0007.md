# D-0007 — The census counts only what is in the village: a count of 0 is skipped

Accepted 2026-09-29. Rusty, in a Terralith fortified village at -16849, -12164 on the server:
`/deed buy` failed with "An unexpected error occurred trying to execute that command", and so did
`/deed here` and `/deed appraise` run as him there. The error's tooltip read "n", the message of
`Census.Builder.block`'s precondition (a count is positive). No log line: vanilla prints a command's
stack trace only with debug logging, and its message only in the tooltip.

**Cause.** The census counts a chunk section's priced blocks with `PalettedContainer.count`.
Vanilla reports only the states present in the section. The server runs Lithium 0.15.4, whose
`chunk.serialization.PalettedContainerMixin` replaces `count`: it tallies the storage into an
array indexed by palette id and reports every palette entry, including an entry the section no
longer holds, with a count of 0 (read in the server's jar). A palette keeps an entry until the
section is resized or saved and loaded again, so any change to a priced block in a loaded chunk
leaves one: a barrel opened and closed (its `open` state), a furnace lit and gone out, a chest or
lantern broken, the churn of the village generating. The villages bought before were likely
freshly loaded from disk, which drops stale entries.

**Rule.** The census skips a count of 0 or less before looking the state up; the domain's
precondition stands, since the adapter now passes only what is there.

Rejected: dropping the precondition in `Census` (it caught the fault; a wrong count should not
be summed in silence); counting by walking the section's blocks (4,096 reads a section where the
palette count is one pass).

Verified by `aStateNoLongerInTheVillageCountsNothing`, with Lithium 0.15.4 (Modrinth
`DDUrRVCA`, the server's jar by SHA-1) on the gametest server: a barrel opened and closed and a
chest broken inside the hut; the census counts one barrel and no chest. It failed on 2.2.0 before
the fix with the message "n", as on the server. The other GameTests pass with Lithium loaded.
